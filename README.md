# 像素原野跳跃

零依赖的原创 Canvas 横版跳跃游戏。

## 打开方式

在当前目录启动静态服务器：

```bash
python3 -m http.server 8123
```

然后打开：

```text
http://127.0.0.1:8123/
```

也可以直接双击打开 `index.html`。

## 操作

- `←` / `→` 或 `A` / `D`：移动
- `空格` / `↑` / `W`：跳跃
- `Shift`：奔跑
- `X` / `J`：火花形态发射火球
- `P`：暂停
- `R`：重开

## 玩法

小形态开局。问号砖在小形态时给蘑菇，变大后可撞碎砖块；大形态再顶道具砖会得到火花，可发射弹跳火球。星星提供约 10 秒无敌。碰到敌人时，大形态会退回小形态；小形态会损失一条命。到达右侧旗杆即可通关。
